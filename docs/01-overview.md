# 01 · 项目概览

RTLForge是面向自然语言RTL需求的本地研究工程平台，当前版本0.3.0。
它让候选实现拥有明确合同、工具证据、失败分类和可追溯修复历史。

控制台已实现从需求澄清、SpecIR/TaskTree、生成、静态检查和仿真，到可选Vivado MCP综合的闭环。
支持失败候选续跑、输出截断扩容、五类Memory检索和通用已有模块集成。
独立TB由验证器使用，不发送给生成或修复Agent；没有独立TB时明确标注验证范围。

完整BM本地案例通过160帧独立仿真及OOC综合；它证明集成流程可运行，不证明研究机制的普遍收益。
源码、评测和本地专项材料的公开边界见[状态与验收矩阵](STATUS_ZH.md)。

原项目书全部目标尚未完成：Compose、异步整理、外部文档RAG、波形摘要及正式消融仍有缺项。
现有Web、批量入口与控制台的能力尚未统一。项目止于综合，不以布局布线/板级验证为交付目标。
